# Security

If you find a security vulnerability in Windissect, please report it privately
instead of opening a public issue:

- Email **raze.crs@proton.me**, or
- Send a direct message to the maintainer on the
  [Windissect Discord](https://discord.gg/wveT8zFCus). Don't post the
  details in a public channel.

Include the version (`windissect --version`), what an attacker could do, and
the steps to reproduce it. You'll get a reply within a few days, and credit in
the release notes and in #thanks once it's fixed, unless you'd rather not be
named.

Bugs in Windows itself that you find *with* Windissect aren't Windissect
vulnerabilities; report those to Microsoft (MSRC).
